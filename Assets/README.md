# CoFleet assets

All checked-in app icon PNGs are original CoFleet artwork generated by
`Scripts/generate-app-icons.swift`. Regenerate them with:

```bash
Scripts/generate-app-icons.sh
```

The design is a geometric fleet/constellation mark. It contains no OpenAI,
Codex, Pokémon, or other third-party logo or character artwork.

No pet art ships in this repository. Pet packages are user-imported at runtime
and remain subject to their owners' licenses.
