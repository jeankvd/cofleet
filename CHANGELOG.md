# Changelog

All notable changes to CoFleet will be documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and releases use
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Clean Codex-only repository foundation for macOS, iOS, watchOS, widgets, and
  complications.
- Authenticated multi-host architecture, native Apple surfaces, notes, todos,
  and user-imported pet support.
- Live host activity and current-task synchronization across Progress, Agent
  Bay, Active, iPhone, and Apple Watch.
- Codex Companion handoff that opens the canonical task on the Mac that owns
  it, including requests initiated from iPhone.
- Five-item session paging, reconnect-safe thread snapshots, and responsive
  native controls for models, reasoning, permissions, approvals, and turns.
- SceneKit Battle presentation on Mac and iPhone plus a lightweight Watch
  presentation driven by the same fleet state.
- Reproducible build, test, privacy, security, and publication gates.

### Changed

- Refined the public UI to match the compact CoFleet visual language across
  Apple platforms while keeping Codex as the canonical source of task state.
